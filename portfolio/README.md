# Abdelrahman Ahmed — AI Portfolio

A modern, responsive, single-page portfolio built from the information in the provided CV.

## Run locally
Just open `index.html` in a browser.

## Deploy
You can upload the folder to GitHub Pages, Netlify, Vercel, or any static hosting service.

## Personal photo
No photo is required for this version. The hero uses an "AA" monogram instead, so the design stays clean. A real professional photo can be added later without changing the layout.
